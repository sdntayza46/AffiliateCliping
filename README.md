## What It Does
- **Studio Video Editor UI:** Top 9:16 interactive preview canvas with horizontal workspace tabs (`Format`, `Framing`, `Shield & FX`, `Clips`).
- **Originality Shield:** Toggle horizontal mirror (`hflip`), subtle color grading (`+2%` contrast / `+3%` saturation), audio pitch shift (`+3%`), clean `16px` white frame, and speed/luma micro-grain to bypass TikTok duplicate detection without altering product colors.
- **Fast-Seek Engine:** Per-segment keyframe input seeking and single-pass scaling for fast rendering even on long 12+ minute recordings, with full elapsed time reporting.
- **Multi-Clip Generation:** Output 1 to 5 distinct clips per recording with varied cuts.
- **In-App Updates:** Check and install new builds directly inside the app.
