## What It Does
- **Studio Video Editor UI:** Top 9:16 interactive preview canvas with horizontal workspace tabs (`Format`, `Framing`, `Shield & FX`, `Clips`).
- **Multi-Account Anti-Duplicate Matrix + mvhd Max Patch:** Exporting 2–5 clips automatically gives each clip a unique fingerprint (alternating horizontal mirror, studio frame thickness/shade, micro-pan/zoom, vocal pitch/EQ, and opening hook order) combined with the `mvhd max` container patch.
- **Originality Shield:** Toggle horizontal mirror (`hflip`), subtle color grading (`+2%` contrast / `+3%` saturation), audio pitch shift (`+3%`), clean studio frame, and speed/luma micro-grain without altering product colors.
- **Hybrid Fast-Seek & Exact A/V Sync:** Fast keyframe pre-seeking combined with millisecond-accurate `trim`/`atrim` and `48 kHz` sample-rate normalization for zero lip-sync drift on long 12+ minute recordings.
- **In-App Updates:** Check and install new builds directly inside the app.
